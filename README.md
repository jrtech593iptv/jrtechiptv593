# JR TECH - Plataforma Digital de Entretenimiento 🚀

Sitio web informativo e interactivo para la comercialización de servicios de IPTV y plataformas de streaming.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## 🛠️ Características
* **Reloj Dinámico:** Muestra la hora local en tiempo real usando JS.
* **Cotizador Express:** Cálculo directo con precios promocionales según la vigencia seleccionada.
* **Modo Oscuro / Claro:** Alternancia rápida mediante variables CSS (`dark-mode`).
* **Validación de Datos:** Validación de números celulares en formato local (`09XXXXXXXX`).
* **Diseño Adaptativo (Responsive):** Maquetado con CSS Grid y Flexbox.
